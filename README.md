# Серебряная тетрадь — поэтический блог

Личный поэтический блог в эстетике Серебряного века: тёплый пергаментный фон,
графитовая типографика, бронзовые виньетки. React (Vite) + Firebase (Firestore, Auth).

## Стек

- **React 18 + Vite** — фронтенд
- **React Router v6** — маршрутизация
- **Firebase Firestore** — хранение стихотворений и комментариев
- **Firebase Authentication (Email/Password)** — защита `/admin`
- **CSS-модули** — стили, без UI-фреймворков
- **Vercel** — деплой

## Модель данных (Firestore)

**Коллекция `poems`**
```
{
  id: string (авто),
  title: string,
  content: string,       // текст с переносами строк, строфы разделены пустой строкой
  date: string,           // 'YYYY-MM-DD' — дата написания
  epigraph: string,       // необязательно
  reactions: {             // счётчики реакций, хранятся прямо в документе стиха
    heart: number, clap: number, dove: number, pen: number, fire: number
  },
  createdAt: Timestamp,
  updatedAt: Timestamp     // необязательно, при редактировании
}
```

**Коллекция `comments`** (плоская, с полем `poemId`)
```
{
  id: string (авто),
  poemId: string,
  authorName: string,
  text: string,
  createdAt: Timestamp
}
```

## Настройка Firebase

1. Создайте проект на [console.firebase.google.com](https://console.firebase.google.com/).
2. Включите **Firestore Database** (в тестовом или боевом режиме — правила ниже перекроют доступ).
3. Включите **Authentication → Email/Password** и вручную создайте одного пользователя — это будете вы, автор.
4. В настройках проекта скопируйте конфигурацию веб-приложения и заполните `.env`:
   ```
   cp .env.example .env
   ```
5. Опубликуйте правила безопасности из `firestore.rules` (Firestore → Rules, либо `firebase deploy --only firestore:rules` при наличии Firebase CLI).
6. (Рекомендуется) создайте составной индекс для комментариев, если Firestore попросит его в консоли при первом запросе (`comments`, `poemId` ASC + `createdAt` ASC) — обычно предлагается автоматически по ссылке в консоли браузера при ошибке.

## Локальный запуск

```bash
npm install
cp .env .env   # и заполните ключами из Firebase
npm run dev
```

## Деплой на Vercel

1. Загрузите проект в Git-репозиторий.
2. Импортируйте репозиторий в Vercel.
3. Framework Preset — **Vite**, команда сборки `npm run build`, папка вывода `dist` (определяется автоматически).
4. В настройках проекта Vercel добавьте те же переменные окружения, что и в `.env` (`VITE_FIREBASE_...`).
5. `vercel.json` уже настроен на редирект всех путей в `index.html`, чтобы работали прямые ссылки вроде `/poem/абв123`.

## Возможности

- Главная страница со стихами, сгруппированными по годам и месяцам, с фильтром по году и постраничной подгрузкой ранних лет.
- Полное сохранение строф и переносов строк при отображении.
- Панель эмодзи-реакций (❤️ 👏 🕊️ ✍️ 🔥) со счётчиками, хранящимися в Firestore.
- Комментарии в реальном времени (без регистрации, по имени).
- Защищённая паролем админ-панель: список рукописей, создание, редактирование, удаление.
- Полностью адаптивная вёрстка от мобильных экранов до широких десктопов.
